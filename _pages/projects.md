## Asset management platform

Built at Merit Asset Management, spanning a Go REST API, a React/TypeScript admin platform, and a React Native portfolio app.

- Client management, orders, financial ledgers, and product pricing
- Transaction-safe imports, JWT/OTP authentication, and admin authorization
- Automated public-market pricing and manual private-market valuations
- Authenticated PDF previews with local caching and serialized mobile session updates
- AWS deployment and iOS/Android releases

## LLM security for smart contracts

Developed a system combining LLMs and rules to detect price-manipulation vulnerabilities in smart contracts, with **Prof. Shuai Wang at HKUST and Huawei**.

## Autonomous endoscope navigation

Developed an autonomous navigation agent for endoscopes in dynamic environments, with **Prof. Nevin L. Zhang at HKUST and NVIDIA Hong Kong**.

## SemEval 2025 publication

**Co-first author** — Liyuan Guo et al., *Ustnlp16 at SemEval-2025 Task 9: Improving Model Performance through Imbalance Handling and Focal Loss.* SemEval 2025, pp. 1522–1527.

Used focal loss, oversampling, and easy data augmentation (EDA) to address class imbalance and improve BERT and RoBERTa performance.

[Read the paper on ACL Anthology](https://aclanthology.org/2025.semeval-1.200/)

More public code is available on [GitHub](https://github.com/mo3300047).
